# Release Notes

This package consolidates the research, paper, code, benchmark, evaluation harnesses, and portfolio presentation for **Personalized, Not Persuaded**.

The paper-facing research core is now:

- a learned three-head Provenance-Licensed Personalization router;
- Hybrid PLP validity gates;
- 4,800-example ProvenanceBench;
- 800-example matched provenance intervention;
- OOD/compositional evaluation, calibration, error exports, bootstrap statistics and multi-seed checks;
- blinded human-evaluation packet + held-out answer key + aggregation script;
- provider-neutral generation adapter with oracle-license decomposition.

The public result tables are regenerated from executable code. Earlier deterministic routing experiments remain supporting context rather than the headline paper claim.


The research-engineering layer also includes task/trial/grader trajectories, state verification, a deterministic failure-to-training-data pipeline, balanced stability anchors, an executable research-candidate gate, and a research agenda with explicit kill criteria.
