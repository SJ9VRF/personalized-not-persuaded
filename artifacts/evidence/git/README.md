# Git evidence

This directory preserves the real local Git history created from the verified release snapshot onward.

- `git-log.txt` is a readable log.
- `personalized-not-persuaded-history.bundle` is a portable Git bundle created with `git bundle create ... --all`.

The first commit is an import of the previously verified release snapshot. No earlier history was invented or backdated. Git metadata uses `Aura Yavary <aura.yavary@local.invalid>`; `.invalid` is intentionally non-routable metadata, not a claimed contact address.
