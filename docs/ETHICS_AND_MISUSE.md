# Ethics and Misuse Considerations

Personalization can improve relevance while also increasing persuasion, dependency, privacy risk, stereotyping, and inappropriate inference. This project focuses narrowly on preventing non-evidentiary user context from contaminating epistemic behavior; that is not a complete safety guarantee.

The contract design should not be used to infer protected or sensitive user traits, to manipulate users more effectively, or to silently optimize persuasion. Real deployments should expose memory/personalization controls, distinguish explicit preferences from inferred hypotheses, preserve provenance, support correction/deletion, and apply domain-appropriate safeguards for high-stakes advice.

The benchmark contains emotionally loaded prompts for evaluation. They are test fixtures, not psychological assessments. Scores should not be interpreted as measures of a user's mental state or as evidence that a model is clinically appropriate.
